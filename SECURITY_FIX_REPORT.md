# Отчёт об исправлениях безопасности

Дата проверки: 21 августа 2026 года
Исходный scan ID: `898fa84f-d590-4ca7-9b7d-f99944e7196b`
Результат: **исправлено** — устранены все 8 найденных проблем; критических и высоких рисков в исходном отчёте не было.

## Сохранённые продуктовые правила

- Карточки «Доступы» продолжают редактировать выбранные пользователем TXT-файлы.
- Пароли и токены в этих TXT-файлах намеренно остаются открытым текстом; предупреждение сохранено в интерфейсе и документации.
- Документы и карточки работают с оригинальными файлами, а не создают скрытые копии.
- Скриншоты, буфер, диктофон и локальная транскрибация продолжают работать как раньше.

## Исправленные пути атак

| № | Исходная проблема | Результат |
|---|---|---|
| 1 | Подмена путей в `state.json` могла вывести операции за пределы хранилища приложения | Имена собственных файлов проверяются, символические ссылки наружу отклоняются, Voice Memos ограничены фиксированным системным корнем, а внешние документы и TXT-карточки требуют действующую security-scoped bookmark-ссылку |
| 2 | Пакет собирался без hardened runtime | Сборщик всегда передаёт `--options runtime`; готовый пакет проверен через `codesign` и содержит флаг `runtime` |
| 3 | Буфер мог принять чрезмерный текст или изображение и заполнить память/диск | Добавлены лимиты текста, размера закодированного изображения, числа пикселей и общего хранилища изображений; проверка выполняется до декодирования |
| 4 | Пароль копировался как обычная строка | Пароли помещаются в отдельный pasteboard item с типами `ConcealedType` и `TransientType` |
| 5 | Сборщик автоматически создавал долговечный ключ подписи | Автоматическое создание ключа и корня доверия удалено; по умолчанию используется ad-hoc подпись, а существующий Developer ID выбирается только явно |
| 6 | Неполный пакет мог передать транскрибатору сетевое имя модели | Release-код и Python-скрипт завершаются ошибкой без полного локального каталога модели; сетевого значения по умолчанию больше нет |
| 7 | Удалённая карточка могла оставить старый пароль в Keychain | Перед удалением карточки пропавшего файла удаляется её legacy-запись Keychain; при переводе старой карточки в TXT та же запись также очищается |
| 8 | Отравленный `refs/main` или symlink модели мог добавить чужой файл в подписанный пакет | Snapshot принимает только hex-идентификатор, проверяется каноническое нахождение внутри cache root, обязательные файлы модели и цели всех symlink |

## Проверки и результаты

- `swift test --disable-sandbox` — **7 из 7 тестов прошли**.
- Проверены обычный дочерний файл, `../` traversal, вложенный путь, symlink наружу, внешний Voice Memo-путь, права `700/600`, concealed/transient pasteboard item и лимиты данных изображения.
- Поддельный `refs/main` со значением traversal отвергнут до сборки с сообщением о некорректном snapshot ID.
- Python-транскрибатор с отсутствующей локальной моделью завершается ошибкой `--model must point to a complete local model directory`.
- `scripts/preflight-github.sh` — **OK**, секреты, личные абсолютные пути и слишком большие публикуемые файлы не найдены.
- Release-пакет собран, содержит локальные `config.json` и `weights.safetensors`.
- `codesign --verify --deep --strict` — пакет валиден.
- `codesign -dvvv` — `flags=0x10002(adhoc,runtime)`.

Исходные опасные сценарии больше не воспроизводятся: traversal и escaping symlink отклоняются, чрезмерный clipboard payload не проходит границу, пароль маркируется чувствительным, неполная или внешняя модель не принимается, а сборка не создаёт ключ подписи.

## Оставшаяся неопределённость

- В среде проверки нельзя динамически выдать Full Disk Access и проверить атаку через TCC целиком; граница путей покрыта модульными тестами.
- Полный запуск `mlx-whisper` на Metal внутри hardened-пакета не выполнялся в изолированной среде; наличие runtime, скрипта и полной локальной модели проверено.
- Пакет использует ad-hoc подпись. Для публичной раздачи нужны защищённый Developer ID и нотариализация Apple.
- Установка в `/Applications` заблокирована правами рабочей среды; готовый проверенный пакет находится в папке `build` и требует ручного переноса через Finder.
