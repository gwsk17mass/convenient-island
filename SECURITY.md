# Безопасность

## Какие данные хранятся

История буфера, скриншоты, записи, транскрипции и метаданные хранятся локально в `~/Library/Application Support/ConvenienceIsland/`. Каталоги приложения создаются с правами `700`, а файл состояния — `600`.

Приложение не отправляет данные в сеть. Транскрибация работает локально.

Release-сборка использует только модель, вложенную в приложение. Если локальная модель отсутствует или неполна, транскрибация завершается ошибкой и не переключается на сетевой источник.

## Важно о карточках «Доступы»

Карточка намеренно редактирует выбранный пользователем TXT-файл. Email, пароли и токены в этом файле не шифруются. Не сохраняйте такой файл в общую или публичную папку. Это не замена специализированному менеджеру паролей.

## Буфер обмена

История буфера может содержать чувствительный текст. Островок пропускает системные типы, помеченные как concealed или transient, но не может гарантировать, что каждое стороннее приложение правильно маркирует секреты.

Скопированные из карточки пароли также помечаются для macOS как concealed и transient. Это снижает вероятность сохранения совместимыми менеджерами буфера, но общий буфер macOS всё равно не является полностью закрытым каналом.

## Сборка и подпись

Скрипт сборки не создаёт постоянный ключ или доверенный сертификат. По умолчанию применяется ad-hoc подпись с hardened runtime. Для публикации нужно явно выбрать защищённый Developer ID и выполнить нотариализацию Apple.

## Разрешения macOS

- Запись экрана — для скриншотов.
- Универсальный доступ — для управления Apple «Диктофоном».
- Полный доступ к диску — для чтения библиотеки Apple «Диктофона».

Полный доступ к диску и Универсальный доступ — широкие разрешения. Выдавайте их только сборке, которой доверяете.

## Публикация уязвимостей

Не публикуйте действующие секреты в issue. До появления отдельного защищённого канала создавайте issue без секретных данных.
