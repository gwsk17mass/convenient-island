# Островок удобства

Нативный прототип для macOS на SwiftUI и AppKit. Островок находится поверх рабочих столов, раскрывается при наведении, сворачивается после ухода курсора и фиксируется слева, по центру или справа.

## Что уже реализовано

- плавное раскрытие и сворачивание;
- перемещение островка и сохранение позиции;
- снимок экрана через ScreenCaptureKit без окна островка;
- лента и сетка скриншотов, drag-and-drop, удаление в Корзину;
- редактор снимков: кадрирование, кисть, маркер и текст;
- история текстового буфера с повторным копированием и редактированием;
- документы как постоянные ссылки на оригинальные файлы;
- переход к документу в Finder;
- виртуальные папки для снимков и документов;
- карточки доступов, связанные с выбранными пользователем TXT-файлами;
- записи Apple «Диктофона» и локальная транскрибация через `mlx-whisper`;
- локальное JSON-хранилище в `~/Library/Application Support/ConvenienceIsland/`.

## Сборка

Для проверки из терминала:

```sh
swift build
.build/debug/ConvenienceIsland
```

Для создания обычного приложения:

```sh
zsh scripts/build-app.sh
```

Скрипт ожидает Python-окружение `.venv-transcribe` с `mlx-whisper`. Его можно переопределить:

```sh
CONVENIENCE_ISLAND_TRANSCRIBER_PYTHON=/path/to/python3 zsh scripts/build-app.sh
```

Готовый пакет появится по адресу `build/Островок удобства.app`. Локальная сборка по умолчанию использует безопасную временную ad-hoc подпись и включает hardened runtime. Скрипт не создаёт ключи или доверенные сертификаты. Если у вас уже есть собственная подпись разработчика, её можно выбрать явно:

```sh
CONVENIENCE_ISLAND_SIGNING_IDENTITY="Developer ID Application: …" zsh scripts/build-app.sh
```

Для публичного распространения дополнительно потребуются полноценный Xcode, Developer ID и нотариализация Apple.

## Разрешения macOS

При первом снимке macOS запросит разрешение на запись экрана. Доступ к внешним документам и TXT-карточкам появляется только после того, как пользователь сам выберет файл в системном окне.

Apple «Диктофон» требует более широкие разрешения: доступ к его библиотеке и управление интерфейсом. Подробности и известные риски описаны в [`SECURITY.md`](SECURITY.md).
